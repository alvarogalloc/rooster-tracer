Features to add (1-week scope, ~3h/day)

Baseline (current C++ implementation):
- Phong shading (ambient + diffuse + specular) in material.cppm
- Directional/point lights with hard shadows in raytracer_trace.cpp
- Spheres/planes/triangles/OBJ meshes; mesh BLAS BVH only (mesh3d.cpp, bvh.cpp)
- One ray per pixel; no recursion beyond background (raytracer_render.cpp, raytracer_trace.cpp)

1) Gamma correction + simple exposure control (Difficulty 1/10)
   Scope: Apply exposure and gamma (e.g., 2.2) before writing PNG.
   Current scan:
   - color_rgb::to_rgb_255() clamps and scales only; no gamma/exposure (color_rgb.cppm).
   - save_png() uses to_rgb_255 directly (raytracer_io.cpp).
   Needed changes:
   - Add exposure scalar in scene (new directive or constant).
   - Apply exposure + gamma (pow(color, 1/2.2)) before to_rgb_255.
   - Update SCENE_FORMAT.md and scene_parser.cpp if exposure is configurable.
   Scene layout (.rscn):
   ROOSTERSCENEV1
   viewport 640 360
   fov 60
   camera 0 1 4  0 1 0  0 1 0  0.1 50
   background 0 0 0
   max_depth 1
   mat 220 220 220
   point_light 2 4 2 255 255 255 80
   sphere 0 1 0 1 220 220 220
   plane 0 0 0 0 1 0 0
   Reference: https://learnopengl.com/Advanced-Lighting/Gamma-Correction

     (camera.cppm, raytracer_render.cpp).
   - No sampling controls in scene_parser.cpp.
   Needed changes:
   - Add RNG and jitter offsets per pixel.
   - Add "samples" directive or default samples-per-pixel.
   - Accumulate and average color per pixel.

11) OBJ parser robustness (piedad.obj fixes) (Difficulty 3/10)
    Scope: Make OBJ ingestion match real-world exports (Blender).
    Current scan:
    - obj_parser ignores vt/usemtl/s/o/g lines; piedad.obj uses all of them.
    - One mesh + one material id for the whole file; no per-material grouping.
    - No winding validation; backface culling can drop faces if winding is flipped.
    Needed changes:
    - Parse vt and set vertex.uv/has_uv; keep v/vt/vn index triplets.
    - Track mtllib/usemtl; split triangles by material id (one mesh per material).
    - Respect smoothing groups (s): use vn when present; otherwise compute per-face.
    - Add OBJ options: scale + axis conversion (Blender Z-up) + double_sided flag
      that disables backface culling for meshes.
    Scene layout (.rscn):
    ROOSTERSCENEV1
    viewport 1280 720
    fov 60
    camera 0 0.6 2.2  0 0.6 0  0 1 0  0.1 50
    background 10 10 10
    max_depth 1
    mat 200 200 200
    # NEW: obj <path> <tx> <ty> <tz> <material_id> <scale> <double_sided>
    obj piedad.obj 0 0 0 0 1.0 1
